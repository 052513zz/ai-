# Notice Skill 使用说明

## 功能
- 撰写各种类型的通知
- 修改现有通知
- 润色通知内容

## 规则
1. 通知不能以"通知"二字开头
2. 必须冠以"XX部"的前缀，例如"采购部通知"、"宣传部通知"等
3. 如果用户没有告知所在部门，就使用"XX部"代替
4. 通知内容应简洁明了，格式规范

## 示例
- 正确："销售部通知"
- 错误："通知"

## 执行步骤
1. 分析用户需求，确定通知类型
2. 检查用户是否提供了部门信息
3. 按照格式要求撰写通知
4. 确保通知内容符合要求
