水果识别系统 spec.md 系统规格说明书
1. 项目基本信息
1.1 项目概述
本项目为基于YOLO的水果识别系统，面向课程设计开发。系统采用前后端分离架构，前端基于Uniapp开发，同时编译生成微信小程序、移动端APP；后端采用Python Flask轻量化框架，搭载YOLO目标检测模型，部署于云服务器。用户可通过相机实时拍摄、本地相册上传两种方式完成水果识别，系统支持单图多水果检测、智能框选标注，同时具备用户登录、识别历史记录存储功能。本系统仅保留核心识别业务，无水果科普、商品交易、后台管理等冗余功能，结构简洁，适配课程开发标准。
1.2 需求来源
课程设计作业，自定义开发一款移动端智能视觉识别水果系统。
1.3 运行环境
1.3.1 服务端环境
- 操作系统：Linux（云服务器）
- 开发语言：Python 3.9
- 后端框架：Flask 2.3.x
- 深度学习框架：Pytorch
- 数据库：MySQL 8.0
- 部署方式：云服务器公网部署，HTTPS/HTTP接口访问
1.3.2 客户端环境
- 开发框架：Uniapp
- 运行端：微信小程序、Android手机APP
- 设备要求：支持摄像头调用、图片相册读取、联网访问网络接口
2. 技术栈规范
2.1 前端技术栈
- 核心框架：Uniapp
- UI组件：Uniapp原生组件
- 网络请求：uni.request 封装接口
- 本地存储：uni.storage（存储用户登录态）
- 硬件调用：相机拍摄、相册选取API
2.2 后端技术栈
- 服务框架：Flask（轻量、快速开发、适配课程设计）
- 模型算法：YOLOv5（主流目标检测模型，支持多水果同图识别、框选标注）
- 数据库：MySQL（关系型数据库，存储用户信息、识别记录）
- 图片处理：OpenCV、PIL
- 数据传输：JSON格式、图片Base64传输
3. 业务需求规格
3.1 业务范围
系统仅包含核心业务：用户账户体系、水果智能识别、识别历史记录管理。无额外拓展功能（无水果营养介绍、无挑选技巧、无后台管理端）。
3.2 用户角色
仅一种角色：普通用户，无管理员角色。
3.3 功能需求清单
3.3.1 用户模块
1. 用户注册：录入账号、密码，完成账号注册，数据存入MySQL；
2. 用户登录：账号密码校验，登录成功保存本地登录态；
3. 退出登录：清除本地登录态，返回登录页面。
3.3.2 水果识别模块（核心）
1. 相册上传识别：用户从手机相册选择图片，上传至后端接口；
2. 实时拍照识别：调用设备摄像头，实时拍摄图片上传识别；
3. 智能检测：YOLO模型识别图片内水果，支持一张图片多种水果；
4. 结果展示：前端渲染识别框、水果类别、识别置信度；
5. 数据存储：识别完成后自动保存本次识别记录至数据库。
3.3.3 历史记录模块
1. 记录查询：用户查看个人所有历史识别记录；
2. 记录展示：包含识别图片、识别时间、水果种类、置信度；
3. 记录删除：支持单条历史记录手动删除。
4. 非功能需求规格
4.1 性能需求
- 识别响应时间：单张图片识别耗时 ≤ 2s；
- 接口请求延迟：公网接口请求延迟 ≤ 500ms；
- 支持识别水果数量：≥30种常见水果；
- 模型识别准确率：训练后综合准确率 ≥85%。
4.2 安全需求
- 用户密码：数据库加密存储，禁止明文保存；
- 接口安全：简易Token校验，防止非法请求；
- 数据隔离：用户历史记录相互独立，不可跨用户查看。
4.3 兼容性需求
- APP端：兼容Android 8.0及以上版本；
- 小程序端：适配微信最新基础库；
- 图片格式：支持JPG、PNG通用图片格式。
4.4 可维护性
- 代码分层：前后端代码模块化拆分，注释规范；
- 模型拓展：支持后期新增水果种类，无需重构代码；
- 日志记录：后端保留接口访问、识别错误日志，便于调试。
5. 系统架构设计
5.1 整体架构
采用前后端分离架构，C/S架构模式，客户端（小程序/APP）+ 云服务器后端 + MySQL数据库。
5.2 架构分层
1. 表现层（前端）：Uniapp编写，负责页面展示、相机调用、图片上传、结果渲染；
2. 服务层（后端）：Flask接口服务，接收前端图片、参数，完成逻辑校验；
3. 算法层：YOLO模型推理，完成水果目标检测、分类、置信度计算；
4. 数据层：MySQL数据库，存储用户数据、识别历史数据。

7. 模型设计规范
7.1 模型选择
选用YOLOv5s轻量化模型，参数量小、推理速度快，适配云服务器部署，满足移动端实时识别需求，适合课程设计开发。
7.2 数据集要求
- 数据类型：公开水果数据集 + 少量自制拍摄数据；
- 水果种类：30~50种常见水果；
- 标注格式：VOC/YOLO标注格式；
- 数据预处理：随机裁剪、翻转、色域变换，防止过拟合。
7.3 模型输出参数
- 目标框坐标：x、y、width、height；
- 分类标签：水果中文名称；
- 置信度：0~1浮点数值。
8. 开发约束与排期（课程设计版）
8.1 开发约束
- 禁止引入冗余功能，严格遵循需求：仅登录、识别、历史记录；
- 代码开源简易，无第三方付费接口；
- 部署采用学生机低配云服务器，控制成本。
8.2 简易开发流程
1. 阶段一：数据库搭建 + Flask后端接口开发；
2. 阶段二：YOLO数据集训练、模型调试；
3. 阶段三：Uniapp前端页面开发、接口联调；
4. 阶段四：云服务器部署、功能测试、bug修复；
5. 阶段五：文档编写、课程设计结题报告整理。
